# Gardula — Frontend

The web frontend of **Gardula**, a personal finance management application designed to help users organize their accounts, track financial transactions, manage credit cards, and monitor their financial activity.

## 🚧 Project Status

**MVP — Personal validation phase**

The application has reached its initial MVP stage, with core screens and backend API integration in place. The current focus is on using the application in real-life scenarios, identifying issues, and prioritizing improvements based on actual usage.

## 🎯 Features

- [x] Account management
- [x] Transaction management
- [x] Credit card management
- [x] Financial reports

## 🛠️ Tech Stack

- **React** — UI development
- **TypeScript** — static typing
- **Vite** — development server and build tooling
- **Tailwind CSS** — styling
- **React Router** — client-side routing
- **React Hook Form** — form management
- **Zod** — data validation
- **TanStack Query** — asynchronous server-state management, where used
- **Recharts** — charts and data visualization
- **Lucide React** — icons
- **Framer Motion** — animations, where used

## 🎨 Design

Gardula follows a modern fintech and SaaS-inspired visual identity, using shades of purple as its primary colors.

The interface focuses on clarity, consistent layouts, and intuitive navigation to make financial information easier to understand.

## 📁 Project Structure

The frontend is organized around application features, with components, services, types, and utilities separated to support maintainability and gradual evolution.

The structure is refined as the application grows, prioritizing separation of concerns and component reusability.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- The Gardula backend API configured and running

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd <repository-folder>
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will display the local URL in the terminal.

### Backend Integration

The frontend communicates with the Gardula backend API to retrieve and manage financial data.

Make sure the backend is running and the API URL is correctly configured before using the integrated features.
